# ava

Expense tracking as physical receipts — a small experiment in tactile UI.

## the first round

Kraft, gingham, thermal slips.

- **Chooser** — [https://rayzorzrb.github.io/ava-receipts/](https://rayzorzrb.github.io/ava-receipts/)
- **the drawer** — [drawer.html](https://rayzorzrb.github.io/ava-receipts/drawer.html) — August, already full. Tap a slip, open a box.
- **drop** — [drop.html](https://rayzorzrb.github.io/ava-receipts/drop.html) — a new receipt prints and lands in the pile.
- **sort** — [sort.html](https://rayzorzrb.github.io/ava-receipts/sort.html) — a messy stack, and the boxes waiting at the bottom.

## more realistic

3D boxes, Apple chrome.

- **studio** — [studio.html](https://rayzorzrb.github.io/ava-receipts/studio.html) — white studio. The 3D tray is the month.
- **table** — [table.html](https://rayzorzrb.github.io/ava-receipts/table.html) — spatial product shot, and a + that prints.
- **cells** — [cells.html](https://rayzorzrb.github.io/ava-receipts/cells.html) — boxes as objects, receipts as iOS list cells.

Pure HTML/CSS/JS. Served from `main` `/` on GitHub Pages. No login; sample data only; currency is ₹.

# ava (iOS)

Native SwiftUI version of the oak-tray expense app.

## Open it
1. On a Mac, clone or pull `rayzorzrb/ava-receipts`.
2. Open `ios/Ava/Ava.xcodeproj` in Xcode 16.
3. Pick an iPhone simulator (iOS 17+).
4. Set your team under Signing if you want a device.
5. Run.

His honey-oak tray and the thermal slips are in `Ava/Assets.xcassets`. Receipts sit whole on the tray floor (no clip mask). Dummy August, ₹.
